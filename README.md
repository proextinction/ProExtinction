# Pro Extinction · Website

The new Pro Extinction website in design B (Poster), in 29 languages (EN, DE, PL, ES, IT and the fully AI-translated FR, PT, RU, ZH, HI, AR, BN, UR, ID, JA, TR, VI, KO, FA, MR, TE, TA, SW, TH, NL, UK, TL, PA, GU; Arabic, Urdu and Persian right to left), light and dark.
Design A (Ember) is removed; it is still on the branch `backup/vercel-2026-10-06`.

Check (before every commit): `python tools/check.py` rebuilds everything and checks links, hreflang, other servers, security headers and secrets.
Build: `python tools/build_all.py` (Windows, Mac, Linux; on Mac/Linux maybe `python3`).
Preview: `python tools/serve.py`, then open http://localhost:8000. The pages need a server because the links are addresses like `/de/manifest`.

## Search engines (SEO)
Every page has a title, a description (`content/seo/`), a canonical link, `hreflang` links to all language versions, Open Graph data for sharing (picture `site/og.png`) and, on the home pages, Schema.org data about the organisation. `site/sitemap.xml` lists all pages with their language versions.
**Open to search engines:** `INDEXABLE = True` in `tools/build.py`. The switch controls the meta tag, `X-Robots-Tag` (in `site/_headers`) and `robots.txt` together. A legal page with placeholders in square brackets stays closed to search engines.
Domain: `SITE_URL` in `tools/build.py` (`https://proextinction.com`). Old English addresses (`/manifesto`, `/home` …) redirect to the new ones; `/` forwards old links of the single-file version (`#/de/manifest`).

Address extras for testing: `?theme=light` or `?theme=dark`, `?motion=on` (despite "reduce motion").

Hidden effects (`tools/smoke.js`, `tools/eggs.js`): smoke at the end of long pages; stars that go out on "Cosmic Extinction" while reading; click the logo five times quickly (the page fades, the last sentence of the manifesto appears); birth counter in the footer (humans, ~farm animals, ~wild animals, ~insects; rough estimates from yearly figures, `BORN` in `tools/build.py`); a greeting in the browser console. With "reduce motion" only soft fades.
